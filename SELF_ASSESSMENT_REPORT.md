## What We Did Not Manage

- **Provider-side configurable spending cap / dashboard capture (Criterion 2):** We selected Groq API's Free Plan (`openai/gpt-oss-20b`, \$0/month paid budget), where Groq only provides configurable spend caps on paid tiers. Rather than enabling paid billing just to set a cap, we documented the Free Plan policy and rate limits in [`README.md`](README.md) and [`docs/security.md`](docs/security.md); an external redacted screenshot of the owner's Groq billing/plan page has not yet been attached.
- **Full frontend, database, and live LLM agent integration (planned for PA#3–PA#5):** Per the project roadmap, Next.js UI (`apps/web`), PostgreSQL persistence, live Groq tool-calling orchestration, and the shared 150-place dataset are not implemented in PA#2; `POST /plans/{planId}/save` currently executes against an in-memory deterministic store and checked sample dataset.
